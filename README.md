# 2026 Japan Salary & Tax Wall Calculation Engine (手取りHub)

Open-source calculation engine for Japanese Part-time Income Walls (103万, 106万, 130万, 160万, 178万) and Overtime Pay based on MHLW & NTA standards.

### 🚀 Production Live Web Application
Official Web Tool: [https://tedorihub.com/kabe.html](https://tedorihub.com/kabe.html)

### Features
- 103万・106万・130万・178万円の壁判定
- 47都道府県の最低賃金自動判定
- 労働基準法第37条に基づく残業代計算
